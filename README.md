# 📱 QR Master für Android

Eine moderne und benutzerfreundliche QR-Code-App für Android.
Scanne QR-Codes blitzschnell, führe intelligente Aktionen aus (Links öffnen, anrufen, WhatsApp), verwalte deinen Scan-Verlauf und erstelle eigene QR-Codes direkt auf deinem Smartphone.

2. Die Datei `app-release.apk` auf deinem Android-Gerät öffnen.

# ✨ Features:
Scannen: QR-Codes und Barcodes blitzschnell mit der Kamera scannen.

Intelligente Aktionen:

🌐 Links direkt im Browser öffnen

📞 Telefonnummern anrufen

💬 Direkt zu WhatsApp weiterleiten

📋 Gescannten Text in die Zwischenablage kopieren

Verlauf: Alle Scans werden lokal gespeichert und können später eingesehen, kopiert oder erneut verwendet werden.

Generieren: Eigene QR-Codes erstellen und als Bild in der Galerie speichern, teilen oder den Text kopieren.

# 🛠️ Technologien:
Diese App wurde mit Flutter und Dart entwickelt. Folgende Pakete werden verwendet:

mobile_scanner (Kamera & Scannen)

qr_flutter (QR-Code Generierung)

url_launcher (Intelligente Aktionen)

shared_preferences (Lokaler Verlauf)

share_plus & gal (Teilen & Speichern)
